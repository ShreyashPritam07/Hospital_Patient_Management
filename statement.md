# Project Statement

## Problem Statement
Small hospitals and clinics need a simple way to maintain basic patient records. Manual handling can make it difficult to add, view, search, and remove records consistently. This project provides a menu-driven Python application for basic patient record management.

## Scope
The system supports adding patient details, displaying all stored records, searching for a patient by name, deleting a patient record, and exiting the application. Data is maintained in memory during the current program session.

## Target Users
- Students learning Python programming and data management.
- Small clinic or hospital staff needing a basic prototype for patient-record operations.

## High-Level Features
- Add patient records.
- View all patient records.
- Case-insensitive patient-name search.
- Delete patient records by name.
- Input validation and user-friendly error messages.
